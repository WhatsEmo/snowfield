# Snowfield

A cozy Christmas town with cute creatures.

Snowfield is a look for the Claude desktop and mobile apps. It draws an animated night scene behind the conversation.

## What the scene shows

- A snowy valley at night, with a full moon, stars and a soft purple glow
- Three layers of hills with small houses, lit windows and chimney smoke
- A decorated tree, gifts, a candy cane and two snowmen
- Slimes, orange mushrooms and snails that move, stop and turn
- Slow parallax motion between the layers, and snow that falls

All the art is original vector art.

## Install

At the prompt of a terminal session:

```
/plugin install snowfield --marketplace WhatsEmo/snowfield
```

Type `y` to add the marketplace, then select a scope.

From a shell:

```
claude plugin install snowfield --marketplace WhatsEmo/snowfield
```

## Screen size

The look is built for a 2560 x 1440 external display.

The scene changes its size with the width of the window, so it also works at other sizes. On a very different screen, the village can look smaller or larger than intended.

## Notes

- The look forces dark mode, because the scene is a night scene.
- The desktop and mobile apps draw the look. The terminal and the editors do not draw it.
- The look needs a Claude Code version that has the `Backdrop` component.
- The scene becomes still for a person who uses the reduced-motion setting.
